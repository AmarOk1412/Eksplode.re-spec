# Contract: Sound, Music and Settings (web page)

Presentation only (no rules). Module `crates/web/assets/audio.js`, served at `/audio.js`. Every sound is generated at run time from oscillators and noise; no audio file, sample or third-party melody is used or fetched.

## Start-up and lifecycle

- The audio context is created on the first `keydown`, `pointerdown` or `touchstart`; before that nothing plays and nothing errors.
- If `AudioContext` is missing or throws, every call becomes a no-op.
- `document.hidden` suspends the context (music stops); becoming visible resumes it.
- Three gain buses: `master` -> destination, `music` -> master, `effects` -> master. Effective gain: `muted ? 0 : value`; changes ramp over 50 ms.

## Settings

```json
{"music":0.35,"effects":0.7,"muted":false}
```

Stored under `localStorage["eksplode.re.audio.v1"]`; values clamped to 0..1; invalid or unreadable storage gives the defaults above. The settings panel has two sliders (music, effects), a mute toggle and a "test sound" button; it opens from the join screen, the lobby and the match (a small speaker button).

## Sound effects

| Id | Trigger (source) | Recipe |
|----|------------------|--------|
| `click` | button pressed in the menu or lobby | 40 ms square tick, 1.2 kHz |
| `bombPlace` | event `BombPlaced` | 80 ms triangle blip falling 520 -> 330 Hz |
| `explosion` | event `BombExploded` | 600 ms white noise through a low-pass falling 3000 -> 120 Hz plus a 60 Hz sine thump; volume scaled down for several in one tick |
| `bonus` | event `PowerUpCollected` with a bonus | rising three-note arpeggio (C5 E5 G5), 60 ms notes |
| `malus` | event `PowerUpCollected` with a malus | falling sawtooth buzz 400 -> 120 Hz, 250 ms |
| `punch` | event `BombPunched` | 120 ms noise burst plus a pitch drop 700 -> 200 Hz |
| `land` | event `BombLanded` | 90 ms sine thud 140 Hz |
| `eliminated` | event `PlayerEliminated` | descending four notes, 100 ms each |
| `win` / `draw` | event `RoundEnded` (winner / other) | win: rising major fanfare; draw: two low tones |

Events come from the `events` list of each `Snapshot`; each event produces at most one sound per snapshot per id, and at most 8 sounds start per snapshot.

## Music

A lookahead step sequencer: a 25 ms timer schedules notes up to 120 ms ahead on the audio clock. Tunes are built from fixed patterns generated by a small seeded generator (fixed seeds), so the notes are identical on every run.

| Tune | When | Tempo | Material |
|------|------|-------|----------|
| `lobby` | join screen and lobby | 96 BPM | C major pentatonic arpeggio over a 4-bar bass, soft triangle lead, light noise tick |
| `match` | during a match | 144 BPM | A natural minor, driving 8th-note bass, 2-bar melodic loop, noise hi-hat |

Tunes loop; switching tune fades the old out and the new in over 300 ms. When a round ends the match tune stops and the result sound plays; the lobby tune returns with the lobby.

## Documentation of origin (FR-023)

`docs/AUDIO.md` lists every sound and tune, its recipe and that it is generated by the game; a node test checks that every id in the code appears in that file.

## Tests that bind this contract

Node tests with a fake audio context: no context before a gesture; settings load, clamp and save; gain values for muted and levels; event-to-sound mapping and per-snapshot caps; music scheduler schedules the expected notes for a fixed horizon and loops; tune switching; hidden-page suspend/resume; missing `AudioContext` is harmless; `docs/AUDIO.md` lists all ids. Manual checklist: listening to each sound and both tunes, volume changes heard within 0.2 s.
